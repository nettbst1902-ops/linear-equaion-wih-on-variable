สมการเชิงเส้นตัวแปรเดียว

เรียนรู้การหาคำตอบของสมการด้วย "วิธีลองแทนค่าตัวแปร" (Trial and Error Method)

กิจกรรมที่ 1: ตราชั่งสมการเรียลไทม์

ลองปรับค่า x ด้านล่าง
สมการปัจจุบัน
2x + 3 = 11
0
ขั้นตอนการแทนค่า (Step-by-Step)

แทนค่า x = 0 ใน 2x + 3

ฝั่งซ้าย (LHS) = 2(0) + 3 = 3

ฝั่งขวา (RHS) = 11

3 ≠ 11 สมการเป็นเท็จ

แบบทดสอบท้ายกิจกรรม (ประเมินความเข้าใจ 3 ข้อ)

1

ข้อใดคือคำตอบของสมการ 4x - 5 = 7 ?

2

เมื่อแทนค่า x = 3 ในสมการ 5x + 2 = 17 สมการจะเป็นจริงหรือเท็จ?

3

สมการ 12 - 2x = 6 มีคำตอบคือเท่าใด?

คะแนนของคุณ: 0 / 3
